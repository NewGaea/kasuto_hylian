# aku

# Neo-Modern Hylian
## Alternative Forms

## Etymology
From [**aka**](lexicon/lexemes/a/aka.md) "here," inflected as an independent pronoun.

## Pronunciation
- **IPA Broad**: /'a.ku/

## Pronoun

### aku (plural *akiu*)
1. here, this place
2. now, this time

This pronoun can only be used where it would otherwise be proper to use a noun phrase, and not where one should otherwise use the adverbial [**akok**](lexicon/lexemes/a/akok) to modify a verb or another phrase.
