# aktaita

# Neo-Modern Hylian
## Alternative Forms
- **akta•iag**: (archaic, Kasutan form) original romanized spelling by Kasuto

## Etymology
From [**akte**](lexicon/lexemes/a/akte) and [**aite**](lexicon/lexemes/ai/aite), the first two letters of the Modern Hylian script in formal order.

## Pronunciation
- **IPA Broad**: /akt.'ai.tag/

## Verb

### aktaitag (present *aktaitas*, past *aktaites*, future *aktaitos*)
1. learn to read a script, learn to write a script
2. alphabetise
