# Hirlërde Hilañva - Chapter 1: Basic Sentence Structure

The first question most people will ask about a new language is how to say various things – and we hold to the old adage that if we give you the fish, you will eat for the day, but if we teach you to fish, you may eat for the rest of your life. So we are going to teach you how to structure a sentence in Modern Hilañve before we go any further or go into details. This lesson may seem awkward, for we will use only a few words in Hylian and will focus on teaching you how to form the simplest of sentences.

It is important to understand the word order in Hylian to make a sentence, so we’ll begin with the most basic sentences: Intransitive sentences.

## Intransitive Sentences

An intransitive sentence is a sentence which only has a subject and a verb. For example:

```ngloss
\ft Link walks.
```

In Modern Hylian, you would construct this sentence similarly:

---
```ngloss
\ex Lïnkera promas.  
\ft Link walks.
```
---

We will explore verbs more in a later lesson, and will limit ourselves to the _-ag_ and _-as_ forms for now, which are the dictionary and present tense forms.

## Transitive Sentences

Transitive sentences have both a subject and an object in them. For example:

---
```ngloss
\ex Lïnkera lërdas ab raz lërde.  
\ft Link reads a book.
```
---

What is Link reading? A book! “Link,” is the subject, and “a book,” is the direct object. A sentence can have more than one object, too, specifically it can have one (or more) indirect objects.

| Hylian       | English                  |
| ------------ | ------------------------ |
| _bënkati_    | welcome, greetings       |
| _vina_       | good, well               |
| _hire, hira_ | one                      |
| _tairag_     | to be, being             |
| _taz_        | the                      |
| _raz_        | a, an                    |
| _ab_         | direct object particle   |
| _ank_        | indirect object particle |
| _diarag_     | to give, giving          |
| _zhatag_     | to say, saying           |
| _lërde_      | book                     |
| _goere_      | food                     |
| _promag_     | to walk, walking         |

## Indirect Objects

An indirect object is the beneficiary, recipient, or target of a verb, but not the thing to which a verb is done. In English these sometimes take on the form of _prepositional phrases_ such as “to X” or “for X.”

---
```ngloss
\ex Zëldase diaras ab taz lërde bënkata ank Lïnkera.
\ft Zelda gives the introduction letter to Link.
```
---
```ngloss
\ex Zëldase diaras ank Lïnkera ab lërde bënkata.  
\ft Zelda gives Link an introductory letter.
```
---

Note that both forms of the sentence are valid, as long as you prefix each of the object phrases with the right particle, though there is a common tendency to keep direct objects before indirect objects in casual speech.

Articles are not strictly necessary in Neo-Modern Hylian, though they are preferred in formal situations. Likewise, pronouns can be left out if they are well defined by the context of speech or writing.
