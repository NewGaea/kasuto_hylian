# Standards for Link's Awakening

Unlike many older video games, the addresses for standard Latin text are largely the same as in Unicode or ASCII. The formatting codes are the same in both the Original and DX versions.

## Line Formatting

Text lines are limited to 16 characters, and are space-padded to occupy all 16 bytes on the line.

Each Dialogue is terminated with \FF.

In the credits, text lines are 18 characters.

## Command Codes

23 23 23 23 23 = $FILENAME
5E = ' (apostrophe)
EE = **+** (Directional Pad)
F0 = ${\uparrow}$ (D-Pad Up/Up Arrow)
F1 = ${\downarrow}$ (D-Pad Down/Down Arrow)
F2 = ${\leftarrow}$ (D-Pad Left/Left Arrow)
F3 = ${\rightarrow}$ (D-Pad Right/Right Arrow)
FE = End Menu Choice
FF = End Dialogue
